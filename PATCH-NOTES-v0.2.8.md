# Battle Army Tools v0.2.8

## GM Deployment / Assignment
- Added **Deploy / Assign Units** to the GM Battle Actions toolbar.
- Uses the existing anchor-based formation deployment workflow.
- GM can choose unit type, quantity, formation, spacing, direction, team/alliance, and commander.
- Added **Player Owner** selection. Deployed tokens receive OWNER permission for that player.
- Battle-unit data records the assigned player ID/name for auditing and future battle controls.
- Player assignment is independent of commander assignment, so a GM can assign a formation to both a player and a commander.
- Deployment is GM-only.
