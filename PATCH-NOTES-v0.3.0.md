# Battle Army Tools v0.3.0

- Bakes the Battle Turn Tracker directly into the module.
- Adds a GM-only **Turn Tracker** button to Battle Actions.
- Player **End My Turn** advances the active side in the tracker.
- The final player turn stops at **waiting for GM to advance the round**.
- Only the GM can **Advance Round**.
- Advancing the round returns the tracker to the first side and refreshes unit movement/attack state and commander command tokens.
- GM can configure tracking mode and turn order from the built-in tracker.
